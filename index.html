                      ¿Borrar tus datos?

                      Se eliminarán de este dispositivo tus títulos, con tus fechas y notas. No se puede deshacer.

                      Tus otros dispositivos, la clave y los datos descargados de TMDb no se tocan. Si tienes datos.csv en GitHub, se volverán a cargar al abrir la app desde allí.

                      Datos e imágenes de películas: TMDb. Esta app usa la API de TMDb, pero no está avalada ni certificada por TMDb.
                      Cómo exportar de IMDb: abre tu lista (o "Your Ratings"), pulsa los tres puntos ⋯ → Export, y descarga el CSV desde "Exports". El archivo no sale de tu dispositivo.
                      Sincronizar dispositivos: si subes tu CSV al repositorio de GitHub con el nombre datos.csv, la app lo cargará sola en cualquier dispositivo que la abra desde GitHub Pages.
